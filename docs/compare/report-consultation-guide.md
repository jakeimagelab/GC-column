# 사전 상담 가이드 구현 보고

## 되돌리기 기준

- 구현 전 체크포인트: `6931c0f` (`Checkpoint before consultation guide`)
- 이 커밋 이후 변경만 되돌리면 기존 사이트 구조로 복귀할 수 있다.

## 구현 범위

- `/consultation`에 진료 전 정보 가이드 추가
- 고민, 상담 우선순위, 예산, 선택 입력을 바탕으로 원장 검수 데이터 안에서 비교 가능한 시술 정보를 표시
- 효과 요약, 한계, 주의사항, 근거 칼럼, 비용 검수 상태를 함께 표시
- 홈 질문 영역에 사전 정보 가이드 진입 링크 추가
- 입력값은 브라우저 상태에서만 사용하며 API, 쿠키, 로컬 저장소, DB로 전송하거나 저장하지 않음
- 페이지는 현재 `noindex`이며 데이터 상태가 `review_required`일 때 내부 검토 배너를 표시

## 안전 경계

- 진단, 처방, 효과 보장, 개인별 시술 확정 문구를 사용하지 않음
- 실제 비급여 금액은 임의로 작성하지 않고 모두 `null`로 두어 “비용 정보 원장 검수 전”으로 표시
- 연령대와 성별은 선택 항목이며 결과 우선순위에 사용하지 않음
- 공개 전 필요한 값: 실제 금액 범위, 원장 승인일, 시술별 금기·주의 기준, 병행 시술 규칙

## 함께 수정한 UX 문제

- 준비되지 않은 영문·중문 링크를 비활성 상태로 변경
- 준비되지 않은 시술 링크의 오해를 부르는 `role="link"` 제거
- 칼럼 메인 가짜 페이지 번호를 실제 전체 칼럼 링크로 교체
- 칼럼 메인 예약·카카오 버튼을 실제 설정값에 연결
- 홈·칼럼 푸터의 링크처럼 보이는 문구를 실제 링크로 교체
- 검색·목록에는 공개 가능한 칼럼만 노출하도록 정리
- 미래 날짜였던 공개 샘플 칼럼 날짜를 현재 확인일로 정리
- Q&A 개인정보 동의 자리표시를 검토 가능한 기본 문구로 교체

## 확인 결과

| 항목 | 결과 | 확인 방법 |
| --- | --- | --- |
| 운영 빌드 | 통과 | `npm run build` |
| 상담 입력 흐름 | 통과 | Chrome에서 고민·우선순위·예산 선택 후 결과 확인 |
| 결과 카드 | 통과 | 온다·울쎄라 비교 카드, 한계·주의·출처 표시 확인 |
| 미검수 금액 차단 | 통과 | 모든 결과에 “비용 정보 원장 검수 전” 표시 |
| 입력 비저장 | 통과 | 저장 API·브라우저 저장소 사용 없음 |
| 색인 차단 | 통과 | 페이지 메타데이터 `noindex` 설정 |
| 반응형 구조 | 통과 | 기존 1440/1024/390 미디어 규칙과 공통 헤더·푸터 재사용 |
