# 글로리의원 사진 배치 1차 분석

작성일: 2026-11-17

## 분석 범위

- 새 사이트의 실제 사진 슬롯과 화면 비율
- 전달 폴더의 사진 159장(프로필, 연출, 인테리어, 가족사진, 인증·상패)
- 현재 `gloryclinic.co.kr`에서 유지할 정보 축(대표원장, 시술·장비, 시설, 위치)
- 현재 새 사이트에 이미 반영된 히어로·프로필·시설·장비 이미지

현재 운영 사이트는 자동 캡처 도구에서 본문을 정상 추출하지 못했으므로, 이번 문서는 운영 사이트의 픽셀 단위 디자인 비교가 아니라 **새 사이트 슬롯과 원본 사진의 용도 적합성 중심 1차 배치안**이다.

## 결론

사진 수와 품질은 충분하다. 문제는 부족이 아니라 **역할별 분류가 아직 안 된 것**이다.

1. 히어로 3장에 같은 `Glory_F_0020.jpg`를 반복할 이유가 없다.
2. 홈은 `진료 장면 → 선택 기준 → 실제 시술` 순서로 사진 이야기를 만들면 된다.
3. 칼럼 페이지는 시술 장면보다 `설명하고 판단하는 원장` 사진이 우선이다.
4. 장비·시술 카드는 사진만 보고 장비를 오인하지 않도록, 리프팅 장비는 공식 누끼를 기본으로 쓴다.
5. 시설 갤러리는 이미 반영한 이름 있는 6장이 번호 사진보다 완성도가 높으므로 유지한다.
6. 가족사진과 상패는 메인 비주얼이 아니라 진료 철학과 신뢰 근거에 제한적으로 쓴다.

## 시술별 카드 사진 원칙

### 리프팅 장비

울쎄라, 써마지, 티타늄, 온다, 튠페이스, 슈링크, 올리지오, 세르프는 이미 확보한 공식 장비 누끼를 사용한다. 연출 사진만으로는 어떤 장비인지 식별이 어렵고, 다른 장비 사진을 잘못 연결하면 신뢰도가 크게 떨어진다.

- 카드 배경: 현재 토프색 계열 유지
- 이미지: 투명 배경 공식 누끼
- 사람 시술 사진: 해당 장비를 확실히 식별할 수 있을 때만 상세 칼럼 내부 보조 이미지로 사용

## 칼럼 카드 사진 운영안

칼럼 카드 4~7개에 서로 비슷한 주사 장면을 반복하면 광고 배너처럼 보인다. 아래처럼 질문의 성격을 나눈다.

- 장비 비교 칼럼: 공식 장비 2개를 나란히 보여주는 편집 이미지
- 선택 기준 칼럼: `Glory_F_0066.jpg` 또는 `Glory_F_0073.jpg`
- 시술 후 관리 칼럼: `Glory_F_0065.jpg` 또는 `Glory_F_0069.jpg`
- 실제 시술 원리 칼럼: `Glory_F_0091.jpg`
- 리쥬란·보톡스·필러: `0029`, `0032`, `0033`을 각 1회만 사용

같은 사진은 홈 히어로, 칼럼 히어로, 칼럼 카드 중 **최대 1곳의 주인공 이미지**로만 쓰고, 다른 곳에서는 보조 이미지로도 반복하지 않는 편이 좋다.

## 가족사진·상패 사용 판단

- 가족사진 `0136~0139`: “가족에게 할 수 있는 시술만”이라는 철학과 의미는 맞지만, 메인 히어로에 쓰면 사적인 인상이 강하다. 원장 소개 상세에서 작은 에피소드 이미지로만 쓰고 공개 동의를 다시 확인한다.
- 상패·인증서 `0140~0153`: 개별 대형 이미지로 늘어놓지 않는다. 원장 상세의 `정품 장비·교육·인증` 근거 영역에 3~5개만 선택한다.
- 추천 우선: `0147~0152` 장비 인증 패, `0153` 정품·사용 인증 자료.

## 현재 상태에서 발견한 핵심 문제

1. 히어로 3장이 모두 `Glory_F_0020.jpg`라 슬라이드의 문구 변화가 사진으로 전달되지 않는다.
2. 홈과 칼럼 원장 소개가 같은 프로필을 써 두 페이지가 같은 화면처럼 느껴진다.
3. 칼럼 히어로, 진료 원칙 3장, 헤더 메뉴 5장, 시술 카드 17장이 아직 비어 있다.
4. 최신 칼럼 카드의 `ImageSlot`은 현재 사진 데이터와 직접 연결되어 있지 않아 사진을 골라도 코드 연결 작업이 필요하다.
5. 리프팅 장비 카드와 주사 시술 카드는 같은 사진 체계로 처리하면 안 된다. 장비는 공식 누끼, 주사·피부 시술은 현장 사진으로 나눠야 한다.
