# 콘텐츠 편집 슬라이드 구현 보고

## 접속

- 로컬 개발 서버: `http://localhost:3000/content-board`
- 기존 `?edit=1` 편집 툴 하단의 **콘텐츠 슬라이드** 버튼으로도 이동 가능
- 개발 모드에서만 페이지와 저장 API가 동작한다. 운영 빌드에서는 페이지와 `/api/dev-content-board`가 404를 반환한다.

## 사용 흐름

1. 왼쪽에서 페이지와 섹션을 선택한다.
2. 가운데 **실제 디자인** 캔버스에서 해당 홈페이지 섹션을 그대로 보며 글자를 직접 클릭해 수정한다.
3. 사진은 Finder에서 실제 디자인 속 사진 자리로 끌어 놓는다. 같은 자리에 사진이 있으면 교체 확인 창이 열린다.
4. 오른쪽 패널에서 글꼴·크기·굵기·색·정렬 또는 이미지 크롭·위치·투명도·컬러·그라데이션을 조정한다.
5. PC와 모바일 배치를 따로 조정하고, 섹션 상태와 개발 메모를 기록한다.
6. 모든 변경은 별도 작업지시서인 `content-brief/content-board.json`에 자동 저장된다.

기본 캔버스는 실제 홈페이지를 1440px 또는 390px 뷰포트로 렌더링한다. **크게 보기**를 누르면 좌우 패널을 접어 실제 디자인을 크게 확인할 수 있고, **항목 목록**은 사진·문구를 빠르게 훑는 보조 보기로 남겨 두었다.

`content-brief/`는 Git에서 제외되며 실제 `content/site-content.json`은 이 화면에서 수정하지 않는다. 사용자가 **편집 슬라이드 반영해줘**라고 요청하면 이 작업지시서를 읽어 정식 콘텐츠와 화면 코드에 반영하는 구조다.

## 구현 범위

- 공통 헤더·상담 메뉴·푸터, 홈 8개 섹션, 칼럼 메인 8개 섹션, 원장 프로필, 칼럼 상세 공통을 총 22개 슬라이드로 분리
- 실제 디자인: 현재 사이트를 동일 출처 iframe으로 렌더링하고 선택한 섹션으로 자동 이동, 레이아웃·색·여백·반응형을 실제 화면 그대로 표시
- 텍스트: 화면 직접 편집, 줄바꿈, 선택 영역 굵게(Cmd/Ctrl+B), 글꼴 7종, 크기·굵기·행간·자간·색·정렬
- 이미지: Finder 드래그 앤 드롭 및 파일 선택, 교체 확인, 원본 파일명 보존, 30MB 제한
- 이미지 배치: 드래그 이동, 휠 확대/축소, 방향키 이동, 100~300%, PC/모바일 개별값
- 이미지 효과: 종횡비 크롭, 투명도, 컬러 오버레이, 4방향 그라데이션
- 관리: 자동 저장 상태, 섹션 진행 상태, 항목·섹션별 개발 메모, 전체 진행률
- 저장: 원본은 `content-brief/uploads/`, 편집값은 `content-brief/content-board.json`

## 확인 결과

| 항목 | 결과 | 확인 방법 |
|---|---|---|
| 운영 빌드 | PASS | `npm run build` 타입 오류 없이 완료 |
| 실제 디자인 표시 | PASS | 1440px/390px 실제 페이지 렌더링, 선택한 원장 소개 섹션으로 자동 이동 확인 |
| 글자 직접 수정 | PASS | 실제 디자인의 `home.doctor.eyebrow`를 contentEditable로 수정 후 JSON 값 확인 |
| 글꼴·크기·정렬 | PASS | Nanum Pen Script / 52px / 가운데 값 저장 확인 |
| 이미지 넣기·교체 확인 | PASS | 실제 디자인의 원장 사진 자리에 SVG를 드롭해 업로드·즉시 미리보기·저장 확인 |
| 실제 화면 사진 조정 | PASS | 원장 사진 위 휠 입력 후 확대 100→105% 및 JSON 저장 확인 |
| PC·모바일 개별 배치 | PASS | PC 100%, 모바일 x/y 52/52·160% 저장 확인 |
| 투명도·컬러·그라데이션 | PASS | 72%·35%·60% 값 동시 저장 확인 |
| 새로고침 유지 | PASS | 저장 후 새로고침하여 텍스트·이미지·효과값 유지 확인 |
| 실제 사이트 콘텐츠 분리 | PASS | 테스트 후 `content/site-content.json` 변경 없음 확인 |
| 브라우저 오류 | PASS | Chromium 콘솔 오류 0건(개발 서버 preload 경고만 존재) |
