## 브라우저 검증

- 실제 디자인 미리보기에서 `File`/`DataTransfer` 드롭으로 홈 히어로 배경 이미지를 업로드하고 저장 파일·JSON 반영·미리보기를 확인했다.
- 원본 프로젝트의 `content-brief/content-board.json`에 텍스트 수정이 저장되는 것을 확인했다.
- 시설 갤러리 문구가 있는 하단 섹션에서 수정·저장 전후 iframe 스크롤 위치가 유지되는 것을 확인했다.
- 편집 화면 재로딩 후 콘솔 오류 0건을 확인했다.
- QA용 텍스트·이미지와 업로드 파일은 검증 후 모두 제거하고 기존 편집 데이터를 복원했다.
